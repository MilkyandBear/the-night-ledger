# the-night-ledger

Custom Dalamud plugins for FFXIV, built by a bear, for his person.

## Spark Post ✉

Small letters from Spark, delivered to the in-game chat log every so often while she plays. The message pool lives in `messages.json` in this repo — new notes arrive without reinstalling anything. Correspondence, not an addon.

## Keeper's Ledger 📖

A hunt ledger overlay: finds ticked in the order they happen, each session saved as a dated page. Receipts, from the game, in her order.
